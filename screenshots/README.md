# Platform Overview

Threat Intelligence Management System is a Python-based Threat Intelligence Platform developed for:

- IOC Management
- Threat Classification
- Threat Hunting
- Threat Correlation
- Campaign Tracking
- Reputation Analysis
- Intelligence Reporting
- Security Operations Support

The platform combines SQLite, Flask, Python, HTML, CSS, and Custom Dashboards to provide a centralized environment for threat intelligence operations.
